Arithmetic

Calculate the factorial, sum, and average of the first N natural numbers.

01 / Input
N

Use a positive whole number (1, 2, 3, …).

How it works: Calculations use the numbers 1 through N.
02 / Results OUTPUT
Factorial N! = 1 × 2 × … × N
—
Sum N × (N + 1) / 2
—
